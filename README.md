O Movie Romantic nasceu de uma ideia simples e especial da minha namorada de termos um espaço para organizar filmes que queremos assistir juntos. A estrutura principal da página e o desenvolvimento do front-end foram feitos por mim, utilizando HTML, CSS e JavaScript. 

Para algumas partes do JavaScript relacionadas ao armazenamento dos filmes no navegador e para a publicação do projeto, utilizei um agente de IA como apoio técnico. Ele também me ajudou a entender melhor como realizar a hospedagem do projeto utilizando a Vercel. 

O objetivo foi transformar uma ideia pessoal em uma aplicação web funcional e praticar conhecimentos de desenvolvimento web.
