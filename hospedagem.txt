COMO HOSPEDAR NA INTERNET - FILMES FAVORITOS
=============================================

Seu site precisa de Node.js + PostgreSQL. O caminho mais simples e tudo
em um lugar so: Railway (site + banco na mesma conta).

  Railway  ->  https://railway.app

Alternativas (dois servicos separados):
  - Render (site) + Neon (banco)
  - Fly.io, VPS, etc.

O codigo ja usa a variavel DATABASE_URL no server.js.


OPCAO RECOMENDADA: RAILWAY
--------------------------

1. Codigo no GitHub
   - Crie conta em https://github.com
   - Novo repositorio (ex: filmes-favoritos)
   - Envie os arquivos do projeto SEM node_modules e SEM .env
     (pode usar "Upload files" no GitHub se nao usar Git no PC)

2. Conta no Railway
   - Acesse https://railway.app
   - Entre com GitHub e autorize

3. Novo projeto
   - "New Project" -> "Deploy from GitHub repo"
   - Escolha o repositorio filmes-favoritos

4. Banco PostgreSQL
   - No projeto, clique em "+ New" ou "Add Service"
   - Escolha "Database" -> "PostgreSQL"
   - O Railway cria o banco sozinho

5. Ligar o banco ao site
   - Clique no servico do seu app (Node)
   - Aba "Variables" (Variaveis)
   - "New Variable" -> "Add Reference" (ou "Connect")
   - Selecione o PostgreSQL -> variavel DATABASE_URL
   - Salve

6. Configuracao do app (se o Railway nao detectar sozinho)
   - Settings do servico Node:
     Build Command:  npm install
     Start Command:  npm start

7. Deploy
   - Aguarde ficar "Active" / verde
   - Em "Settings" -> "Networking" -> "Generate Domain"
   - Copie a URL publica (ex: filmes-favoritos.up.railway.app)

8. Teste no celular
   - Abra a URL em qualquer rede (Wi-Fi ou 4G)
   - Cadastre um filme de teste


ALTERNATIVA: RENDER + NEON
--------------------------

Se preferir nao usar Railway:

  Banco:  https://neon.tech  -> copie a Connection string
  Site:   https://render.com -> Web Service do GitHub
  Variavel no Render: DATABASE_URL = connection string do Neon

Build: npm install
Start: npm start


ANTES DE PUBLICAR
-----------------

- Nunca suba o arquivo .env para o GitHub
- Filmes do PostgreSQL no seu PC nao vao para a nuvem sozinhos
- Plano gratis pode "dormir" apos inatividade (primeira visita mais lenta)


RODAR NO PC (LOCAL)
-------------------

1. PostgreSQL ativo
2. Arquivo .env com DB_PASSWORD (veja .env.example)
3. node server.js
4. http://localhost:3000
